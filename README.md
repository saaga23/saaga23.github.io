# saaga23.github.io

Personal research portfolio of **Sunday Aspita Abraham** — AI Engineer & NLP Researcher.

**Live site:** https://saaga23.github.io

## Stack

- Pure HTML/CSS/JS (no build step, no dependencies)
- Deployed via GitHub Pages
- Mobile-first responsive design

## Structure

```
├── index.html          # Homepage
├── research.html       # Research themes and methodology
├── publications.html   # Full publication list with verified statuses
├── projects.html       # Selected research and engineering projects
├── talks.html          # Presentations, talks, and community roles
├── cv.html             # Web-based CV
├── contact.html        # Contact information
├── css/
│   └── style.css       # Global styles
├── js/
│   └── main.js         # Minimal JS (mobile nav toggle)
└── assets/
    └── cv/
        └── Sunday_Aspita_Abraham_CV.pdf  # Downloadable CV
```

## Updating Content

All content is static HTML. To update:

1. **Publications / Projects / Talks:** Edit the corresponding HTML file directly. Content is curated from primary sources (papers, GitHub, official pages).
2. **CV PDF:** Replace `assets/cv/Sunday_Aspita_Abraham_CV.pdf` with the latest version.
3. **Styling:** Edit `css/style.css`. Variables are defined in `:root`.
4. **Deploy:** Commit and push to `main` branch. GitHub Pages deploys automatically.
